# Contributing

Contributions are welcome through focused GitHub pull requests.

## Development

1. Use Node.js 22 or newer.
2. Run `npm ci`.
3. Make the smallest change that solves the issue.
4. Add or update unit tests.
5. Run `npm run format`, `npm run check`, `npm test`, and `npm run build`.

Never commit Telegram IDs, usernames, tokens, provider credentials, server addresses, private paths, SQLite databases, logs, prompts, model output, or copied production configuration. Use placeholders in tests and documentation.

Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
